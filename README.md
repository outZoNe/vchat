# VChat - Simple WebRTC Video Chat

Простой видеочат типа Discord «на минималках».

В папке [src](src) - расположен SFU сервер на Rust который используе библиотеку `sfu = "=0.5.0"`

В папке [public](public) - расположен "фронтенд", который на чистом JS и был сильно навайбкоден (мне лень заниматься фронтом) `:(`

## 🚀 Как запустить

### 1. Подготовьте конфигурацию

``` bash
cp .env.example .env
```

Отредактируйте файл под свои нужды.

Настроить список комнат и названий можно в [config.js](public/js/config.js)

------------------------------------------------------------------------

### 2. Соберите и запустите весь стек

``` bash
docker compose build && docker compose up -d
```

------------------------------------------------------------------------

## 🐳 Примечание

Команда:

``` bash
systemctl enable docker
```

Скорее всего, вам не пригодится - но пусть будет тут на всякий случай
🙂
